# Next Wedding Template

This folder holds the **complete, ready-to-reuse invitation build** as it stood before the site
was converted into a "Thank You For Coming" page.

`index.html` here is the full invitation: envelope-open animation, hero video, Event Details,
The Program, Dress Code, Gifts, Location & How to Get There, and Travel & Stay.

## How to reuse for the next wedding
1. Copy this `index.html` back to the project root (overwriting the thank-you page).
2. Swap the couple names, dates, venue, program times, map coordinates and directions.
3. Replace assets in `../img/` and `../video/` (hero video, poster, room tours, decor, icons).
4. Update the `<title>`, Open Graph / Twitter meta tags and `CNAME` if the domain changes.

The shared media lives in `../img/` and `../video/`, so keep this file at the project root
(or copy those folders alongside it) when publishing.
